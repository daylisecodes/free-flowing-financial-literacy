# Asset and Source Notes

## Original project assets
- Interface layout, color system, CSS artwork, cards, icons built with CSS, written explanations, and JavaScript interactions were created for this project.
- No stock photographs, third-party icon packs, agency seals, government logos, or copied website layouts are included.
- System fonts are used; no redistributed font files are bundled.

## Source approach
- Financial facts are paraphrased from CFPB, SEC Investor.gov, and FTC materials and cited on `public/sources.html`.
- U.S. government material is handled conservatively: facts are paraphrased and cited instead of reusing agency graphics or page designs.
- Scripture quotations are faithful World English Bible quotations. WEB text is public domain; the name “World English Bible” is a trademark used only to identify the translation.

## Privacy-first design
- No login, account, database, file upload, bank connection, brokerage connection, or credit-report connection.
- Learning-tool entries are browser-side only in this build.
- No contact form is included.
- Vercel Web Analytics is enabled on the public deployment and disclosed in the Privacy Policy.
