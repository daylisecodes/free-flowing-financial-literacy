# Free Flowing Financial Literacy

A faith-centered, privacy-conscious financial education web app built as a public portfolio project. It teaches general financial concepts without providing individualized financial, investment, lending, tax, legal, credit-repair, or real-estate advice.

## Live demo

**Live demo:** https://free-flowing-financial-literacy.vercel.app

## Why I built it

The goal is to make foundational money concepts easier to understand through a consistent **Learn → Practice → Check → Reflect** experience while keeping Jesus at the center of stewardship without promising financial outcomes.

## Learning modules

1. Money Foundations
2. Saving & Emergency Funds
3. Debt & Credit
4. Home Buying & Equity
5. Investing Basics
6. Scams & Financial Red Flags
7. Faith & Financial Stewardship

## Interactive features

- Monthly cash-flow snapshot
- Emergency-savings goal illustration
- Debt-to-income (DTI) calculator
- Home upfront-cost learning range
- Simple home-equity arithmetic
- Hypothetical compound-growth illustration
- Simplified fee-impact illustration
- Scenario-based scam education
- Module quizzes and session-only progress
- Faith/stewardship reflection check-in

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript
- Node.js local development server
- Vercel static hosting + Web Analytics (live deployment)

## Privacy and responsible-design choices

- No accounts or logins
- No application database
- No file uploads
- No bank, brokerage, or credit-report connections
- No contact form in this release
- Calculator and quiz inputs are handled client-side and are not intentionally saved
- Dedicated Privacy, Disclaimer, Terms, About, and Sources pages
- Vercel Web Analytics is disclosed in the Privacy Policy

## Sources and accuracy

Core financial education is paraphrased from authoritative public education sources, primarily the Consumer Financial Protection Bureau (CFPB), SEC Investor.gov, and Federal Trade Commission (FTC). APA-style references and source-use notes are included on the site. Scripture quotations use the public-domain World English Bible text.

## Original / copyright-conscious assets

The UI, CSS-built visual elements, favicon, and project-specific social artwork were created for this project. No third-party stock photos, icon packs, agency logos, or copied page designs are bundled. See `ASSET_AND_SOURCE_NOTES.md` and `COPYRIGHT_AND_SOURCE_NOTICE.md`.
