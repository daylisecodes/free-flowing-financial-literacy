# Project QA Checklist

Use this when reviewing the complete app in one pass.

## Home page
- [ ] Teal/cream/gold visual style feels right
- [ ] All seven module cards are easy to understand
- [ ] Faith language feels centered on Jesus without promising financial outcomes
- [ ] Disclaimer language is visible but not overwhelming

## Module 1 — Money Foundations
- [ ] Sample numbers button works
- [ ] Cash-flow calculator works
- [ ] Clear button works
- [ ] Three-question quiz works
- [ ] Mark-complete button updates progress

## Module 2 — Saving & Emergency Funds
- [ ] Savings calculator works with sample and custom numbers
- [ ] No fixed emergency-fund target is presented as a rule
- [ ] Quiz works
- [ ] Faith reflection feels appropriate

## Module 3 — Debt & Credit
- [ ] DTI calculator works
- [ ] Results do not label a user qualified/non-qualified
- [ ] Credit report vs. credit score explanation is clear
- [ ] AnnualCreditReport.com external link opens correctly
- [ ] Quiz works

## Module 4 — Home Buying & Equity
- [ ] Education checklist count changes when boxes are selected
- [ ] Upfront-cost illustration works
- [ ] Equity arithmetic works
- [ ] No preapproval/readiness promise is made
- [ ] Quiz works

## Module 5 — Investing Basics
- [ ] Compound-growth illustration works
- [ ] Fee-awareness illustration works
- [ ] Risk/loss disclaimers are clear
- [ ] No stock, crypto, fund, or allocation is recommended
- [ ] Quiz works

## Module 6 — Scams & Red Flags
- [ ] All three scenario reveal buttons work
- [ ] Investor.gov link works
- [ ] FTC ReportFraud link works
- [ ] Quiz works

## Module 7 — Faith & Financial Stewardship
- [ ] Scripture wording is correct and identified as WEB
- [ ] Stewardship checklist + reflection result works
- [ ] Faith boundary is clear
- [ ] Quiz works

## Legal / privacy / sources
- [ ] Privacy page accurately describes current deployment setup
- [ ] Disclaimer is easy to find
- [ ] Terms page is easy to find
- [ ] Sources page lists CFPB, SEC Investor.gov, FTC, WEB, copyright, and Vercel references
- [ ] No agency logo, seal, screenshot, stock photo, or third-party icon is present
- [ ] No contact form, login, payment, database, upload, bank connection, or brokerage connection is present

## Mobile check
- [ ] Home page looks good on phone width
- [ ] Module navigation stacks correctly
- [ ] Calculator fields are easy to use
- [ ] Buttons do not overlap
- [ ] Long citations and external links wrap properly
