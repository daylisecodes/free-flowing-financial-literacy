Privacy policy

We built this project to collect as little as practical

Last updated: October 8, 2026. This policy describes the planned public version of Free Flowing Financial Literacy.

Information you type into learning tools

Calculator, quiz, checklist, and reflection inputs are designed to be processed in your browser. This version does not intentionally send those entries to an application database, create an account profile, or save them for later. Refreshing the page resets the tools and module completion marks.

Please do not enter sensitive information

The site does not need Social Security numbers, bank or brokerage credentials, account numbers, tax identification numbers, credit-report files, exact addresses, medical information, passwords, or uploaded financial documents. Please do not put sensitive information into any field.

Hosting and technical logs

The public site is hosted by Vercel. Like other hosting providers, Vercel may process technical request and service information needed to deliver and secure the site, which can include IP address, approximate city/country derived from IP, browser/device information, request details, system configuration, and logs. Vercel's own privacy terms govern Vercel's processing.

Vercel Web Analytics

The public deployment uses Vercel Web Analytics to understand basic site traffic such as page views, visitors, referrers, countries, operating systems, browser information, and routes. Vercel describes its Web Analytics product as first-party and privacy-friendly and states that it does not rely on traditional cookie tracking to follow a visitor across different websites. Analytics are used only to understand site usage and improve the learning experience—not to profile users for individualized financial advice.

Vercel hosting and analytics may still process technical request information under Vercel's own privacy terms. If the analytics configuration changes, or if forms, accounts, advertising, AI features, or other data-collecting services are added, this policy will be reviewed and updated before those changes are used publicly.

Cookies, accounts, advertising, and sales

This project does not intentionally set its own advertising cookies, does not provide user accounts, and does not sell user information. No behavioral advertising system is intentionally included in this build.

External links

The site links to government and other authoritative resources. When you follow an external link, that destination's privacy practices apply.

Contact forms

No contact form is included in this release. That is intentional to reduce unnecessary data collection. If a contact form is added later, this policy will be updated before public use to describe what is collected, why, how long it is retained, and who processes it.

Children

This project is general financial education and is not designed to knowingly collect personal information from children. Because no account or contact form is offered in this release, the site does not intentionally request children's personal information.

Changes

Privacy practices can change if hosting, analytics, forms, accounts, AI features, databases, or other services are added. The policy should be reviewed and updated before each major public release.

Privacy note: This policy is written for this project's current technical design. It is not a substitute for legal advice about obligations that may apply to a future business or materially different version of the site.
