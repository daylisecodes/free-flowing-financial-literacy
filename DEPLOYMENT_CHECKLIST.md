# GitHub + Vercel Deployment Checklist

## Before GitHub

1. Run `npm run check`.
2. Run the site locally with `npm start` and complete `PROJECT_QA_CHECKLIST.md`.
3. Confirm there are no `.env` files, API keys, passwords, private screenshots, or personal financial information in the folder.
4. Confirm Privacy, Disclaimer, Terms, About, and Sources match the actual release.

## GitHub

5. Create a public repository named `free-flowing-financial-literacy`.
6. Push/upload this launch-ready folder.
7. Add 2–4 clean screenshots from the `screenshots` folder to the README after final visual review.
8. Keep `.gitignore`, `COPYRIGHT_AND_SOURCE_NOTICE.md`, and source notes in the repository.

## Vercel

9. Import the GitHub repository into Vercel.
10. Use the included `vercel.json`; the deploy output is the `public` directory.
11. Pick an available free Vercel project URL.
12. Enable Vercel Web Analytics in the project dashboard.
13. Test every public page on desktop and mobile.
14. Verify the Privacy Policy still accurately describes the enabled analytics/hosting configuration.
15. Add the final live URL to this README and your developer portfolio.
16. Add the GitHub repository and live Vercel demo beside Walking With Jesus in the portfolio.
17. Once the live domain is known, add a sitemap with that real domain (do not publish a placeholder domain).
18. Re-run trademark/common-law naming checks before a major commercial launch or trademark filing.
